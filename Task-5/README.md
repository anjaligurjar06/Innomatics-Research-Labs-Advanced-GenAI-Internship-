
# ASSIGNMENT 5 – Real-World Function-Based Problem Solving

##  Overview
This assignment focuses on solving real-time industry-based problems using core Python concepts:

- Functions

Each problem simulates real-world systems used in industries such as Social Media, Healthcare, Agriculture, Banking, IT, E-Learning, and Energy.

##  Problem Descriptions

### 🔹 Problem 1: Social Media – Post Engagement Analyzer
**Goal:** Calculate total likes and classify post performance.  
**Logic:**
- Total Likes ≥ 1000 → Viral Post
- Otherwise → Normal Engagement  
**Industry Use:** Social media analytics platforms, marketing dashboards  

---

### 🔹 Problem 2: Healthcare – Medicine Stock Alert System
**Goal:** Monitor medicine stock levels.  
**Logic:**
- Stock < 10 → Low Stock Alert
- Stock ≥ 10 → Stock Sufficient  
**Industry Use:** Pharmacy management systems, hospital inventory tracking  

---

### 🔹 Problem 3: Agriculture – Rainfall Adequacy Checker
**Goal:** Calculate average rainfall and determine adequacy.  
**Logic:**
- Average ≥ Required Level → Adequate Rainfall
- Otherwise → Inadequate Rainfall  
**Industry Use:** Climate monitoring systems, irrigation planning tools  

---

### 🔹 Problem 4: Social Media – Duplicate Account Detection
**Goal:** Detect duplicate usernames using set data structure.  
**Logic:**
- If duplicates exist → Flag accounts
- Else → Accounts are unique  
**Industry Use:** Platform moderation, fraud detection systems  

---

### 🔹 Problem 5: Healthcare – Appointment Eligibility Checker
**Goal:** Check if patient qualifies for appointment.  
**Logic:**
- Age ≥ 18 → Eligible
- Age < 18 → Not Eligible  
**Industry Use:** Hospital appointment systems, healthcare portals  

---

### 🔹 Problem 6: Agriculture – Premium Crop Price Filter
**Goal:** Filter crop prices above premium threshold.  
**Logic:**
- Price > ₹2000 → Premium Crop
- Else → Regular Crop  
**Industry Use:** Market analytics, export pricing systems  

---

### 🔹 Problem 7: System Monitoring – Application Health Checker
**Goal:** Evaluate application health using error count.  
**Logic:**
- Errors = 0 → Healthy
- Errors ≤ 5 → Minor Issues
- Errors > 5 → Critical Issues  
**Industry Use:** System monitoring tools, IT dashboards  

---

### 🔹 Problem 8: Banking – Daily Transaction Limit Checker
**Goal:** Validate daily transaction amount.  
**Logic:**
- Amount ≤ ₹50,000 → Approved
- Amount > ₹50,000 → Rejected  
**Industry Use:** Banking systems, fraud prevention systems  

---

### 🔹 Problem 9: E-Learning – Student Attendance Eligibility System
**Goal:** Calculate attendance percentage and check exam eligibility.  
**Logic:**
- Attendance ≥ 75% → Eligible
- Attendance < 75% → Not Eligible  
**Industry Use:** Learning management systems, internship tracking platforms  

---

### 🔹 Problem 10: Smart Electricity Bill Analyzer
**Goal:** Calculate electricity bill based on slab system and classify usage.  

**Billing Slabs:**
- First 100 units → ₹3 per unit  
- Next 100 units → ₹5 per unit  
- Above 200 units → ₹7 per unit  

**Usage Classification:**
- Total Bill < ₹500 → Low Usage
- ₹500 – ₹1500 → Moderate Usage
- Above ₹1500 → High Usage  

**Industry Use:** Smart meter systems, electricity billing software, energy analytics
